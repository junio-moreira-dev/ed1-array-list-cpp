# ED1 — TAD Lista — ArrayList

Implementação de uma **Lista Sequencial Estática (ArrayList)** utilizando C++ e conceitos de **Tipo Abstrato de Dados (TAD)**.

O projeto apresenta uma separação entre:

- **Interface abstrata:** define o contrato da lista.
- **Implementação:** utiliza um array dinâmico com capacidade fixa.
- **Testes:** validam as principais operações disponibilizadas pela lista.
